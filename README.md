# **Evil Site. Grabs stuff and sends to discord server, I`ll probably add the VPN detection at some point.**

## *How to use?*

## -Download the "index.html".

## -Add the webhook.
  
###  Make a Discord server.
  
###  Go to Server Settings -> Integrations.
  
###  Make a new webhook and copy the url.

###  Paste the webhook url into the placeholder in index.html.
        
## Host the site. *(recommended way below)*
  
###  Go to vercel.com and sign up.
  
###  Make a new project and upload the index.html file.
  
###  Continue and copy the url it gives you.
        
### Send the url to your victim and wait for a notification in the discord server.
